# AIOLiveTV frontend

React 19 SPA for the AIOLiveTV configurator (rsbuild + TanStack Router).

From the repo root:

```bash
pnpm -F frontend dev
pnpm -F frontend typecheck
pnpm -F frontend build
```

The built output in `packages/frontend/dist` is served by the Node server. See the [root README](../../README.md) for the full workspace.
