---
title: Public Instances
description: AIOLiveTV does not ship official public instances. Self-host or deploy on Vercel.
---

AIOLiveTV is meant to be run as **your own instance**. There is no official public AIOLiveTV instance, and the community AIOLiveTV hosts listed in the original project are **not** AIOLiveTV.

## Recommended options

- [Deploy on Vercel](/getting-started/vercel) with PostgreSQL and Redis
- [Self-host with Docker](/getting-started/deployment)

After the instance is up, open `/stremio/configure`, add XMLTV/M3U/Xtream or live addons, review **Channels**, then save and install the manifest in Stremio.

AIOLiveTV is in **public beta**. Self-host or use Vercel; do not expect a stable public host yet.
