## What is AIOLiveTV?

AIOLiveTV is a **Live TV aggregator** for Stremio. It can:

- Build canonical channels from EPG when XMLTV is present
- Infer and merge channels from stream sources when there is no EPG
- Resolve multiple streams per channel
- Declare Native EPG (`behaviorHints.epgProvider`) only when real EPG data exists

The configuration UI reuses the existing pages **Addons**, **Streams**, **Metadata & Catalogs** and **Miscellaneous**, plus the **Channels** page.
