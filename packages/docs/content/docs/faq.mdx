## General

<Accordions>
  <Accordion title="Is AIOLiveTV production-ready?">
    It is a **public beta** (`0.1.0-beta`). Merged live catalogs, optional Native EPG and the Channels page work. Expect breaking configuration changes before 1.0. Self-host or deploy on Vercel — there is no official public instance.
  </Accordion>

  <Accordion title="Do I need XMLTV?">
    No. Without a guide, AIOLiveTV still lists channels from M3U, Xtream and live addons and merges equivalents. Native EPG (`behaviorHints.epgProvider`) is declared only when a real guide catalog is enabled. See [XMLTV, M3U and Xtream](/guides/sources).
  </Accordion>

  <Accordion title="Why is a channel missing or duplicated?">
    Automatic matching only runs at high confidence (`tvg-id`, then normalised name). Weaker hits stay as suggestions on **Channels**. Disable a channel to hide it from the Stremio catalog. Changes apply after **Save**. See [Channels](/guides/channels).
  </Accordion>

  <Accordion title="Why are there no streams for a channel?">
    Common causes:

    1. The channel is disabled on **Channels**.
    2. The M3U/Xtream addon is disabled or timed out.
    3. **Resources** on the stream source does not include **Stream**.
    4. A local playlist URL was blocked — set `HTTP_ALLOW_PRIVATE_URLS=true` only on a personal LAN instance.

  </Accordion>

  <Accordion title="Should I use a community AIOStreams template?">
    No. Those templates target torrent/Usenet addons that AIOLiveTV does not register. Add XMLTV, M3U or Xtream from **Addons** instead. Follow the [Setup Guide](/configuration/setup).
  </Accordion>

  <Accordion title="How do I edit my configuration after installation?">
    In **Stremio**, click **Configure** next to AIOLiveTV, or open `/stremio/configure` and sign in with the UUID and password.

    After making changes, go to **Save & Install** and click **Save**.
  </Accordion>

  <Accordion title="When do I need to reinstall after making changes?">
    Most changes apply immediately after saving. **Reinstall only when a pop-up tells you to** (usually a manifest change such as the first guide source, which toggles Native EPG).
  </Accordion>

  <Accordion title="How do I back up my configuration?">
    Go to **Save & Install → Backups** and click **Export**. Use **Import** to restore. Toggle **Exclude Credentials** before sharing an export.
  </Accordion>
</Accordions>

## Self-Hosting

<Accordions>
  <Accordion title="Why does Stremio show 'Failed to fetch'?">
    Stremio requires addon URLs over **HTTPS** unless they are on `localhost`. Put Traefik, Nginx or Caddy with a valid certificate in front of AIOLiveTV. See the [Deployment guide](/getting-started/deployment).
  </Accordion>

  <Accordion title="My configuration disappears when I recreate the container">
    Mount a persistent volume for the data directory so SQLite (or your Postgres data) survives recreates:

    ```yaml
    volumes:
      - ./data:/app/data
    ```

  </Accordion>

  <Accordion title="Local XMLTV or M3U URLs fail">
    Outbound HTTP to private and loopback addresses is blocked by default (SSRF protection). On a personal instance that must fetch `http://192.168.x.x/...`, set `HTTP_ALLOW_PRIVATE_URLS=true`. Leave it `false` on any shared host.
  </Accordion>
</Accordions>
