The configurator at `/stremio/configure` has six pages. Filters, Services,
Sorting and Proxy from AIOStreams are **not** shown: live channels are mapped
on **Channels**, not ranked like torrents.

## About

Pick **Simple** or **Advanced**. Simple hides extra formatter and miscellaneous
controls. Sign in here if you already have a UUID and password.

Templates appear only when the instance loads some (`TEMPLATE_URLS` or files
under `data/templates/`). AIOLiveTV does not ship torrent/Usenet templates.

## Addons

Install live sources from the marketplace (XMLTV, M3U, Xtream, Vivo, Claro,
Mi.tv, community live addons) or a **Custom Addon** with a Stremio manifest URL.

On each addon:

- **Name** — label used in stream results
- **Timeout** — how long to wait for catalog, meta and stream
- **Resources** — leave the defaults unless you only want **Stream** from that
  source (so its channels are not listed twice)

**Installed** lists your sources. Refresh catalogues, reorder them, rename them,
or turn one off without deleting it. Advanced users can use
[Groups](/guides/groups) to skip slow backup addons when the primary ones already
returned enough streams.

## Channels

Canonical channels come from EPG when a guide exists, otherwise from stream
sources. High-confidence matches (`tvg-id`, then normalised name) apply
automatically; weaker hits stay as suggestions.

You can enable or disable a channel, accept or reject a suggestion, add a
manual mapping, and change stream order. Nothing is persisted until **Save**.
See [Channels](/guides/channels).

## Formatter

Controls how each stream line looks in Stremio. Use a built-in format or a
custom template. Syntax: [Custom Formatter](/reference/custom-formatter).

The preview is for live HTTP streams. SeaDex and torrent-only tokens from
inherited formats do nothing for live TV.

## Miscellaneous

- **Playback** — stream probe behaviour
- **Display** — Advanced mode only (debug/statistic streams)
- **Parent Config** — inherit addons, formatter, miscellaneous and branding
  from another saved config on this instance

## Save & Install

Create a configuration (UUID + password — store both; they cannot be recovered),
then install the manifest in Stremio or Stremio Web. Copy the Manifest URL for
other devices.

Most edits apply after **Save**. Reinstall only when a pop-up says the manifest
changed (for example the first guide source, which toggles Native EPG).

**Backups** export and import JSON. **Exclude Credentials** strips API keys and
passwords; custom addon URLs are not stripped — check the file before sharing.

## Making changes later

In Stremio, click **Configure** next to AIOLiveTV, or open `/stremio/configure`
and sign in. Edit Addons or Channels, then **Save**.
