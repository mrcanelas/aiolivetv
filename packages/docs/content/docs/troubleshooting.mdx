## Live TV

<Accordions>
  <Accordion title="The catalog is empty">
    Add at least one source with the **Catalog** resource on **Addons**, then **Save**. Disabled channels on **Channels** are omitted. Confirm `/stremio/.../manifest.json` lists a `tv` catalog.
  </Accordion>

  <Accordion title="Stremio has no programme guide">
    Native EPG is declared only when a guide source (XMLTV, Xtream with EPG, Vivo, Claro, Mi.tv) is enabled with **Catalog**. M3U alone never sets `behaviorHints.epgProvider`.
  </Accordion>

  <Accordion title="Local XMLTV or M3U URL is rejected">
    Set `HTTP_ALLOW_PRIVATE_URLS=true` only on a personal instance. Shared hosts must keep it `false`.
  </Accordion>
</Accordions>

## Channels & Streams

<Accordions>
  <Accordion title="A channel is missing or duplicated">
    Automatic matching only runs at high confidence (`tvg-id`, then normalised name). Weaker hits stay as suggestions on **Channels**. Disable a channel to hide it from the Stremio catalog. Changes apply after **Save**. See [Channels](/guides/channels).
  </Accordion>

  <Accordion title="A channel has no streams">
    Common causes:

    1. The channel is disabled on **Channels**.
    2. The M3U/Xtream addon is disabled or timed out.
    3. **Resources** on the stream source does not include **Stream**.
    4. A local playlist URL was blocked — set `HTTP_ALLOW_PRIVATE_URLS=true` only on a personal LAN instance.

  </Accordion>

  <Accordion title="Streams are slow to appear">
    AIOLiveTV waits for the configured addons to respond before returning streams. If one source is slow, playback options are delayed.

    **Fixes:**
    - Lower each addon's **Timeout** to the maximum you're willing to wait (e.g. 5 000 ms).
    - Remove sources you rarely need.
    - Consider using **Groups** to prioritise fast addons — see the [Groups guide](/guides/groups).

  </Accordion>
</Accordions>

## Self-Hosting Issues

<Accordions>
  <Accordion title="Stremio shows 'Failed to fetch' or refuses to connect">
    **Cause:** Stremio requires all addon URLs to be served over **HTTPS**. HTTP is not accepted.

    <Steps>
      <Step>
        Set up a reverse proxy in front of AIOLiveTV. Traefik and Caddy can
        automatically obtain TLS certificates via Let's Encrypt.
      </Step>
      <Step>
        See the [Deployment guide](/getting-started/deployment) for a
        ready-to-use Docker Compose + Traefik example.
      </Step>
      <Step>
        Verify the certificate is valid by opening{' '}
        `https://your-domain/stremio/manifest.json` in a browser. You should see
        a JSON response.
      </Step>
      <Step>Reinstall the addon in Stremio using the HTTPS URL.</Step>
    </Steps>

    <Callout type="info">
      If you're testing locally, Stremio Web (app.strem.io) accepts HTTP
      `localhost` URLs but the desktop app and mobile apps require HTTPS for
      remote URLs.
    </Callout>

  </Accordion>

  <Accordion title="Configuration disappears after updating or recreating the container">
    **Cause:** No persistent volume is mounted for AIOLiveTV's data directory, so the SQLite database is lost when the container is recreated.

    <Steps>
      <Step>
        Stop your containers: `docker compose down`
      </Step>
      <Step>
        Add a volume mapping to your `compose.yaml` under the AIOLiveTV service:

        ```yaml
        volumes:
          - ./data:/app/data
        ```
      </Step>
      <Step>
        Start containers again: `docker compose up -d`
      </Step>
    </Steps>

    See the [Deployment guide](/getting-started/deployment) for a complete, production-ready `compose.yaml` example.

  </Accordion>

  <Accordion title="'Forbidden URL' error when syncing Stream Expressions">
    **Cause:** AIOLiveTV restricts which external URLs can be used for Stream Expression sync by default.

    - **On a public instance:** Ask the host to add your URL to `WHITELISTED_SEL_URLS`.
    - **Self-hosting:** Add `SEL_SYNC_ACCESS=all` to your `.env` to allow any URL.

  </Accordion>

  <Accordion title="The AIOLiveTV container starts but the configure page is blank or errors on load">
    Check the container logs first:

    ```sh
    docker compose logs -f aiolivetv
    ```

    Common causes:
    - **Port conflict** — Another service is using the same port. Change the host port in `compose.yaml`.
    - **Missing environment variable** — Some features require specific env vars (e.g. `PORT`, `BASE_URL`). See [Environment Variables](/configuration/environment-variables).
    - **`BASE_URL` mismatch** — `BASE_URL` must match the public URL your browser uses to reach AIOLiveTV (including the `https://` prefix and no trailing slash).

  </Accordion>
</Accordions>
